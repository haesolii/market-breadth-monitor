# 지표 정의 (Indicator Definitions)

모든 지표는 `backend/app/indicators.py`의 **단일 DuckDB 윈도 쿼리**로 계산된다. 입력은 종목별 일봉
(`date, ticker, close, volume`, 분할 보정)이며, 보통주 유니버스로 이미 제한된 상태다.

## 출처

| 지표 | 출처 | 비고 |
|---|---|---|
| 20% Bull/Bear | 공개 TC2000 검색식 (작업 지시서에 인용된 식) | `C/C5 >= 1.2 AND MINV3.1 > 100000 AND C >= 5` / `C/C5 < 0.8 ...` |
| 4% 일간, 분기/월간/34일 | [How I get Market Monitor numbers (2014-08)](https://stockbee.blogspot.com/2014/08/how-i-get-market-monitor-numbers.html) | Telechart v7 / v12.4 식. **v12.4 기준값 사용** (V ≥ 100000, AVGC20×AVGV20 ≥ 250000) |
| 해석 (임계값 참고) | [How to use market breadth to avoid...(2011-08)](https://stockbee.blogspot.com/2011/08/how-to-use-market-breadth-to-avoid.html) | UI 툴팁에 “해석 참고”로만 표기. 매매 신호로 표시하지 않음 |
| 5/10일 비율, T2108 | 원문에 계산식 없음 | 작업 지시서 정의 + [xang1234/stock-screener](https://github.com/xang1234/stock-screener) (Apache-2.0) `formulas.py`의 관례와 비교. 코드는 복사하지 않음 |

## 계산식 (구현 그대로)

TC2000 표기: `C`=당일 종가, `C1`=1봉 전 종가, `V`=당일 거래량, `MINC65`=당일 포함 최근 65봉 최저 종가,
`AVGC20`·`AVGV20`=당일 포함 20봉 평균 종가·거래량. **봉(bar) 기준**: 각 종목 자신의 직전 봉을 사용한다(TC2000과 동일).

| 컬럼 | 식 | 대상(eligible) 조건 |
|---|---|---|
| `bull` | `C >= C5*1.2 AND C >= 5 AND MIN(V1,V2,V3) > 100000` | C5 존재, 직전 3봉 거래량 존재 |
| `bear` | `C < C5*0.8 AND C >= 5 AND MIN(V1,V2,V3) > 100000` | 동일 |
| `up4` | `100*(C-C1)/C1 >= 4 AND V >= 100000 AND V > V1` | C1, V1 존재 |
| `down4` | `100*(C-C1)/C1 <= -4 AND V >= 100000 AND V > V1` | 동일 |
| `ratio5` / `ratio10` | `SUM(up4, N세션) / SUM(down4, N세션)` (시장 전체 일별 합계) | N세션 모두 존재. **분모 0 → NULL(N/A)**, 무한대 표시 안 함 |
| `quarter_up25` | `100*((C+.01)-(MINC65+.01))/(MINC65+.01) >= 25 AND AVGC20*AVGV20 >= 250000` | 65봉·20봉 모두 존재 |
| `quarter_down25` | `100*((C+.01)-(MAXC65+.01))/(MAXC65+.01) <= -25 AND (유동성)` | 동일 |
| `month_up25` / `month_down25` | `C20 >= 5 AND (유동성) AND 100*(C-C20)/C20 >= 25` / `<= -25` | C20 존재 |
| `month_up50` / `month_down50` | 위와 같고 ±50 | 동일 |
| `day34_up13` / `day34_down13` | `MINC34`/`MAXC34` 기준 ±13 (+.01 보정 포함), 유동성 조건 | 34봉·20봉 존재 |
| `day34_diff` | `day34_up13 - day34_down13` | |
| `t2108` | `100 * COUNT(C > AVGC40) / COUNT(40봉 이상 보유 종목)` | 유동성·가격 필터 없음 (Worden T2108 관례) |

### 거래량 단위
Telechart v7 식(`V >= 1000`, `AVGC20*AVGV20 >= 2500`)은 거래량이 100주 단위였기 때문이며, v12.4(`100000`, `250000`)는
주(share) 단위다. 즉 **일 거래량 10만 주, 20일 평균 거래대금 약 $250,000**. 데이터 소스(Yahoo/Massive)는 주 단위이므로 v12.4 값을 사용한다.

### 워밍업 / 데이터 부족
데이터셋 시작 후 필요한 세션 수(20%: 5, 월간: 20, 34일: 33, T2108: 39, 분기: 64)가 지나기 전 날짜는
**0이 아니라 NULL**로 저장한다. 개별 종목도 윈도가 꽉 차지 않으면 해당 지표 대상에서 제외되며, 지표별 대상 종목 수는
`elig_*` 컬럼(`elig_daily, elig_month, elig_quarter, elig_34, elig_t2108, elig_20`)과 `eligible_universe_count`(해당일 일봉이 있는 보통주 수)에 기록된다.

## 저장 구조

- `data/breadth20.parquet` — `source, date, bull, bear, elig_20, eligible_universe_count, updated_at` (기존 20% 테이블)
- `data/market_monitor_daily.parquet` — 지시서의 `market_monitor_daily` 컬럼 전부 + `elig_*` + `source, updated_at`
- 키는 `(source, date)`. 두 테이블은 `date`(+`source`)로 결합된다 (`/api/monitor`가 결합해서 반환).

## TC2000 / 원본과 일치하지 않을 수 있는 부분 (숨기지 않음)

1. **유니버스**: TC2000 “Common Stocks” 목록과 동일하지 않다. → `docs/data-sources.md` 참조.
2. **생존 편향**: Yahoo 소스는 현재 상장 종목만 포함 → 과거로 갈수록 수치가 작게 나온다 (실측: 5년 평균 약 84%).
3. **분할 보정 시점**: 모든 과거 봉을 “현재 기준” 분할 보정. TC2000도 동일하게 소급 보정하는 것으로 알려져 있으나 확인되지 않았다.
4. **배당 보정 없음**: TC2000 가격 차트처럼 배당 미보정 종가를 사용.
5. **봉 누락**: 거래가 없던 날이 있는 종목은 “봉 기준” 윈도가 달력보다 길어진다 (TC2000도 봉 기준이므로 같은 처리로 추정).
6. **T2108 / 5일 비율**: 원문에 공식이 없어 자체 정의. **원본 공식 수치로 표기하지 않는다.**
7. 원본 수치(예: 110)에 맞추려고 필터를 조정하지 않았다. 차이는 “데이터 관리 → 원본 수치 비교”에 기록한다.

## 다른 시장 적용 (나스닥 · 코스피 · 코스닥)

계산식은 미국과 **완전히 같고**, 금액·거래량 기준만 시장별로 바꾼다 (`backend/app/universes.py`).
아래 한국 기준값은 **원본에 없는 자체 조정값**이며, 화면에도 그렇게 표시한다.

| 시장 | 종목 | 거래소 달력 | 주가 기준 (C, C20) | 거래량 기준 (V, MINV3.1) | 20일 평균 거래대금 | 벤치마크 |
|---|---|---|---|---|---|---|
| 미국 전체 | 미국 보통주 전체 (Yahoo 유니버스) | NYSE | $5 | 100,000주 | $250,000 | S&P 500 (^GSPC) |
| 나스닥 | 위 유니버스 중 NASDAQ 상장 종목 (종합지수 기준) | NYSE | $5 | 100,000주 | $250,000 | 나스닥 종합 (^IXIC) |
| 코스피 | KRX KIND 상장법인목록 (코스피) | XKRX | ₩1,000 | 100,000주 | ₩350,000,000 | 코스피 지수 (^KS11) |
| 코스닥 | KRX KIND 상장법인목록 (코스닥) | XKRX | ₩1,000 | 100,000주 | ₩350,000,000 | 코스닥 지수 (^KQ11) |

- **나스닥**: 공식 나스닥 종합지수는 ADR 등도 포함하지만, 여기서는 미국 보통주 유니버스에서 NASDAQ 상장 종목만 고른다 (ADR 제외). 따로 받지 않고 미국 전체 일봉에서 골라 계산한다.
- **₩1,000**: $5를 환율(₩1,400/$)로 그대로 바꾸면 ₩7,000이 되어 코스닥의 상당 부분이 빠진다. 원 기준의 취지(동전주 제외)에 맞춰 ₩1,000으로 정했다.
- **₩3.5억**: $250,000 × ₩1,400.
- **거래량 100,000주**는 그대로 유지했다 (원본도 주 단위 기준).
- **가격제한폭 처리 (한국)**: 하루 종가 변동이 ±31%(±30% 제한폭 + 반올림 여유)를 넘으면 정상 거래로는 불가능하므로, Yahoo가 반영하지 못한
  액면병합·감자·재상장으로 보고 그 지점에서 종목 기록을 **별개 구간으로 나눈다** (`indicators.cut_breaks`). 어떤 계산 기간도 단절을 넘지 않는다.
  실측: 5년간 코스피 16건, 코스닥 32건 이상의 단절. 이 처리로 코스피 20% 급등 수치가 바뀐 날은 33일(최대 1종목)이다.
- **데이터 누락일**: 해당일 일봉이 있는 종목 수가 최근 20일 중앙값의 절반 미만이면(예: Yahoo 한국 데이터 2025-09-19, 2종목만 존재) 그날은 값을 내지 않는다.
- **색상 강조 기준**: 4%·분기 등 종목 수 기준값은 미국 시장 규모 기준이므로 나스닥·코스피·코스닥에는 기본값을 두지 않는다 (비율·T2108만 기본값). 데이터 관리 메뉴에서 시장별로 설정한다.
